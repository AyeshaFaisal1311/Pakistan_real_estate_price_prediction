# Pakistan Real Estate Price Prediction

A machine learning project predicting property prices in Pakistan using real listing data scraped from Zameen.com.

## Dataset
Download from Kaggle: [Zameen.com Property Data Pakistan](https://www.kaggle.com/datasets/huzzefakhan/zameencom-property-data-pakistan)
Place the CSV file in this project folder before running the notebook.
